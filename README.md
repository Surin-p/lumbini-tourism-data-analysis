# Lumbini Tourism Data Analysis

A data-driven analysis of tourist visitation patterns
to Lumbini, Nepal, from 2014 to 2025.

## Objectives

- Analyze long-term visitor trends
- Compare Nepalese, Indian and third-country visitors
- Identify seasonal tourism patterns
- Examine COVID-19 disruption and recovery
- Analyze international source countries

## Data Source

Official Nepal tourism statistics.

## Tools

- Excel
- SQL
- Python
- Pandas
- Matplotlib
- GitHub
